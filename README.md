# Fall-2025-Campus-DoorDash
A full-stack application designed for the UMBC community, providing an on-campus food delivery service similar to DoorDash but limited to campus locations. Students, faculty, and staff can order from on-campus dining spots, while student workers deliver orders during their free time.

#Backend
Fabricio Rodriguez built the entire application. 
Go was chosen for the backend for performance reasons primarily and how easily it integrates with stripe for payments. 
Postgres/Supabase was my choice for the database. It made authentication significantly easier to implement than rolling custom auth.  
Stripe is the market leader when it comes to payment apis so I integrated it directly. 
Project is approximately 80 percent done on the backend side.
